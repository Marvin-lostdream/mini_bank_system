# mini bank system (c++)

A mini bank system built as practical project while learning C++.
It applies arrays , strings , structs and file handling in a real-world context

## Features
- Client management (Add , Delete , Update , Find)
- Transactions (Deposit , Withdraw , Total Balance)
- Persistent storage using a text file

## Project Structure
- `bankProject.cpp` — main source file
- `inputsLib.h` — input utility header
- `myLibString.h` — string utility header
- `myMathLib.h` — Math utility header


## How to Run
1. Make sure all files are in the same directory.
2. Compile:
   ```bash
   g++ bankProject.cpp -o bank
